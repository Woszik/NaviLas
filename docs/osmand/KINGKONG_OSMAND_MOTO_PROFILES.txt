OsmAnd — profile moto dla NaviLas (KINGKONG 8)
================================================
Data: 2026-09-12 (OsmAnd offline, bez BRouter; Nightly 0.5.74+)

CEL
---
3 style trasy w NaviLas (MOTOCYKL → OsmAnd):

  1. NaviLas krótka  — routing OsmAnd `navilas_short` (turystyczna, mniej autostrad)
  2. NaviLas kręta   — routing OsmAnd `navilas_scenic` (mocniej drogi lokalne)
  3. Motocykl        — standard OsmAnd (wbudowany)

Bez BRouter. Wystarczy OsmAnd + mapa offline PL.

IMPORT PROFILI (1×)
-------------------
Telefon odblokowany. OsmAnd zainstalowany, mapa regionu pobrana.

  A) Z NaviLas: Ustawienia → Wgraj profile NaviLas do OsmAnd
     (albo dialog po pierwszej instalacji OsmAnd z NAWIGUJ)

  B) Ręcznie: Pliki / Downloads → NaviLas_osmand_moto_profiles.osf
     (lub: OsmAnd → Menu ☰ → Ustawienia → Importuj → wybierz plik .osf)

  2. Zaznacz do importu:
     - plik routingu (navilas_moto_routing.xml)
     - profile NaviLas krótka, NaviLas kręta
     - ustawienia globalne (włącza Motocykl)
     Przy duplikacie (wcześniejsze profile NaviLas / Brouter[…]) → „Zastąp”.
     Ten sam stringKey podmienia stare profile BRouter na nowe OsmAnd.

  3. Po imporcie: OsmAnd → Menu ☰ → Ustawienia → Profile aplikacji
     Sprawdź listę:
       ☑ Motocykl
       ☑ NaviLas krótka   (ikona enduro, zielona)
       ☑ NaviLas kręta    (ikona offroad, fioletowa)

WERYFIKACJA
-----------
  a) Profil NaviLas krótka: punkt → Nawiguj → trasa offline, ETA zbliżone do Motocykla
     (nie ~rowerowe 18 km/h).
  b) NaviLas kręta → inna linia (bardziej lokalne drogi).
  c) Profil Motocykl → fabryczny routing OsmAnd.
  d) NaviLas MOTOCYKL → NAWIGUJ → OsmAnd → Krótka / Kręta / Standardowa
     → OsmAnd otwiera się z właściwym profilem (`profile=` w intencie API).

MAPOWANIE → NaviLas
-------------------
  Krótka      → NaviLas krótka   (profile=brouter_trekking)
  Kręta       → NaviLas kręta    (profile=brouter_moped)
  Standardowa → motorcycle (Motocykl)

  stringKey bez zmian względem starych profili BRouter → reimport = podmiana.
  Świeży telefon → profile dodawane obok fabrycznego Motocykla.
