<p>NaviLas helps you find forest rest sites in Poland using open data from the Forest Data Bank (BDL) and OpenStreetMap.</p>
<p><b>Features</b></p>
<ul>
<li>Search near GPS, a map point, or a locality</li>
<li>Map with results and “Zanocuj w lesie” zones</li>
<li>Travel profiles: car and motorcycle</li>
<li>Optional offline BDL data download</li>
<li>Save favourite places with categories and comments</li>
<li>Export and import saved places (JSON backup)</li>
</ul>
<p>The F-Droid build does not check GitHub for updates — use the F-Droid client to update. To switch install channels (GitHub ↔ F-Droid), export saved places before reinstalling.</p>
<p>Not an official app of State Forests or BDL. Information is indicative only — always verify rules and access in official sources.</p>
